UserDefaults · editing

A value is edited in its own shape. A Bool is a switch, a number is a number field, and a collection is rows — one element per field, never a JSON blob to retype. An element that is itself structured is one line of JSON in its row. Data is not editable; it is described and copied.

Rules

  • One density. Every plugin uses --necto-row-height. Two densities read as two applications.
  • One separator. Space or a rule, never both.
  • One status shape. A 200, a 404 and a failure are drawn the same way.
  • Ink for state, colour for status. Selection and focus are ink; success, warning and danger own the colour.
  • Numbers monospaced and right aligned, heading over the digits.
  • No -webkit-font-smoothing. It thins strokes AppKit does not thin.
  • Never hardcode a colour. Take it from the semantic or component layer.
