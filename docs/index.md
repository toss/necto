features:
  - title: Connect everywhere
    details: Connect to an app on a USB device or an iOS simulator. The SDK listens inside your app, so there is no proxy to configure and no certificate to trust.
  - title: Build everything as a plugin
    details: Anything you need for iOS development can be a plugin. Device plugins and desktop plugins are both supported.
  - title: CLI support
    details: Everything Necto does, the CLI does too. Use necto-cli to hand iOS debugging to an agent.
  - title: Built in Swift
    details: The Mac app and the SDK are Swift, and the Mac app owns connections and execution without a separate server process.
